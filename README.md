🚌 Bus Reservation System – Python Project

📌 Project Overview
The Bus Reservation System is a console-based application developed using Python. It allows users to view available bus journeys, check seat availability, book tickets, cancel reservations, and search for booking details.
The project is designed to simplify the bus ticket booking process through a simple, user-friendly menu-driven interface. It uses Python programming concepts such as functions, conditional statements, loops, lists, dictionaries, and file handling.

🎯 Project Objectives
Develop a simple bus ticket reservation application.
Allow passengers to view available journeys and seats.
Manage ticket bookings and cancellations.
Generate a unique booking ID for each reservation.
Calculate ticket fares automatically.
Store booking information for future reference.

✨ Key Features
View Available Buses – Display bus details, routes, departure times, arrival times, and ticket prices.
Check Seat Availability – View the available seats for each bus.
Book Tickets – Enter passenger details and reserve available seats.
Generate Booking ID – Generate a unique booking ID for every successful reservation.
Fare Calculation – Automatically calculate the total ticket fare.
Cancel Booking – Cancel an existing reservation using its booking ID.
Search Booking – Search for passenger and reservation details.
Data Persistence – Save booking information using file handling.
